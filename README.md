
**Brief Description:**
Multimodal deep learning system for kidney tumor malignancy prediction using 3D CT scans, clinical data, and optional radiomics, with built-in explainability.

**Technologies Used:**

* Python
* TensorFlow / Keras
* MONAI
* 3D CNNs
* MLP (clinical data modeling)
* LoRA (Low-Rank Adaptation)
* PyRadiomics
* pydicom, SimpleITK, nibabel
* NumPy, Pandas, Scikit-learn
* Matplotlib, Seaborn
* SHAP, Grad-CAM
* Streamlit
* Joblib
